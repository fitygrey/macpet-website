隐私政策

安心陪伴，数据留在你的 Mac。

开发者：ShuLin Lou

适用版本：macOS 0.1.0

生效日期：2026 年 9 月 18 日

应用内的数据处理

抬头有喵不要求注册账号，不通过应用收集、上传或出售个人数据。当前版本没有广告、分析 SDK、用户行为追踪或云同步。

应用在你的 Mac 本地保存场景缩放、场景宽度、背景显示和小猫睡眠状态等设置。这些信息仅用于恢复应用体验，不会由本应用发送给开发者或第三方服务器。

动画播放和自主活动使用本机时间间隔进行计算，不会上传时间记录。

系统功能

“登录时启动”由 macOS 管理，仅在你主动启用时注册。你可以在应用设置或 macOS 系统设置的登录项中关闭它。

应用不请求访问联系人、相机、麦克风、定位或个人文档。

支持联系

如果你主动发送支持邮件，邮件内容、邮箱地址以及你附带的信息会通过你使用的邮件服务送达开发者，并用于回复和排查问题。请勿发送密码、付款资料或与问题无关的敏感信息。

支持联系邮箱：onebooksoftware@outlook.com。

政策更新

如果应用的数据处理方式发生变化，将更新本政策和生效日期。

网站访问

本网站不使用分析脚本、广告或追踪 Cookie。网站部署到 GitHub Pages 后，GitHub 可能为提供托管服务及保障安全处理 IP 地址等访问日志，具体见 GitHub 隐私声明。
